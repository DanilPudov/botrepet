# Как подключить ассистента к GitHub (чтобы он сам выкладывал файлы)

**Важно:** вы передаёте доступ к репозиторию, а не ко всему аккаунту.
Сделайте токен **только для одного репозитория** и с правом **только на содержимое**.
В любой момент можно отозвать.

## Шаг 1. Создать токен

1. Откройте [github.com/settings/tokens?type=beta](https://github.com/settings/tokens?type=beta)
   (Settings → Developer settings → **Personal access tokens** → **Fine-grained tokens**).
2. Нажмите **Generate new token**.
3. Заполните:
   - **Token name**: `dsh-bot-updater`
   - **Expiration**: `90 days` (или сколько хотите)
   - **Resource owner**: ваш аккаунт
   - **Repository access**: выберите **Only select repositories** → укажите
     репозиторий с ботом (например `repetitor-bot`)
   - **Permissions** → **Repository permissions**:
     - **Contents**: **Read and write** ← это единственное, что нужно
     - **Metadata**: Read-only (ставится автоматически)
     - всё остальное — **No access**
4. Нажмите **Generate token**.
5. Скопируйте токен — он начинается с `github_pat_...`
   (показывается один раз!).

## Шаг 2. Передать токен ассистенту

Вставьте токен в сообщение в чате, например:

```
github_pat_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

Ассистент сохранит его в файл **вне** репозитория:
`D:\Репетиторство DSH\.github_token` (права только для вас, в Git не попадает).

⚠️ Токен окажется в истории чата. Если это неприемлемо — есть альтернатива:
запускать обновление самостоятельно одной командой (см. «Вариант Б»).

## Шаг 3. Что ассистент сможет делать

С токеном он сможет:
- обновлять `bot.py` и другие файлы в репозитории — через GitHub API
  (создаёт коммит «Update bot.py — <описание>»);
- проверять, что файлы в репозитории совпадают с локальными;
- присылать вам ссылку на коммит.

Он **не сможет** менять настройки BotHost — там нужен ваш вход.

# Вариант Б: без передачи токена

Если не хотите давать доступ — ассистент готовит файлы, а вы загружаете сами:

1. Ассистент обновляет файлы в `D:\Репетиторство DSH\bot-git`.
2. Вы открываете репозиторий → **Add file → Upload files**.
3. Перетаскиваете **изменённые** файлы (ассистент скажет, какие именно,
   обычно 1–2: `bot.py` и иногда `sheets_util.py`).
4. **Commit changes** → в BotHost **пересобрать**.

Занимает около минуты и не требует передачи доступа.

---

# Полезно знать

- **Никогда не коммитьте в Git:** `config.json` с токеном бота,
  `service_account.json`, `state.json`. Они уже в `.gitignore`.
- Если токен попал в репозиторий — немедленно отзовите его
  на странице [github.com/settings/tokens](https://github.com/settings/tokens).
- Токен `repo`-класса (старые classic tokens) не нужен: достаточно
  fine-grained с правом Contents.
