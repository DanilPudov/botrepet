## Как пользоваться

1. Взять сценарий из списка или строку из CSV.
2. Воспроизвести шаги в боте (вживую или симуляцией через модули).
3. Сверить с ожидаемым: текст ответа, таблица, лист, строка, ID.
4. Записать расхождение: сценарий, что было, что должно быть.

Запуск автотестов:

```
cd "D:\Репетиторство DSH\bot"
$env:PYTHONPATH="D:\Репетиторство DSH\bot\pkgs"
.\python\python.exe -m pytest tests -q --no-header -p no:cacheprovider
```

Колонки занятий (A..L): время, дата, репетитор, ученик, родитель, сумма, комментарий, первое, как прошло, будут, комиссия, ID.

Колонки учеников (A..I): репетитор, ученик, родитель, тариф, когда добавлен, комментарий, ссылка ученика, ссылка родителя, имя отправителя.

Колонки расписания (A..I): ID, репетитор, ученик, родитель, дни, время, цена, активно, последняя дата.

## Согласованные решения

Это НЕ баги — так задумано:

- **Оплату подтверждает только человек в таблице** — красит ячейку суммы. Из бота подтверждение не делается.
- **Занятие без времени** — напоминание не приходит.
- **Новые записи белые** — бот не перекрашивает суммы.
- **Уведомление об обновлении** — только владельцу, при первом нажатии кнопки.
